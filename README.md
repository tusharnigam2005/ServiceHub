# ServiceHub

## Project Description
ServiceHub is a full-stack MERN web application that connects customers with service providers on a single platform.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

## Features
- User Registration & Login
- Service Listing
- Service Booking
- JWT Authentication
- Responsive UI
